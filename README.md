                <h2>🌟 What is this project about?</h2>
                <p>
                    <strong>StreamLink</strong> is a modern fullstack streaming platform inspired by leading streaming services. It allows users to stream their favorite movies and series anytime, anywhere, with a beautiful, responsive interface and smooth user experience. The project demonstrates authentication, dynamic content delivery, and a polished UI/UX.
                </p>
                <h2>⚙️ Features</h2>
                <ul>
                    <li>📺 <strong>Multi-device Streaming:</strong> Watch movies and TV shows on Smart TVs, game consoles, laptops, tablets, and phones.</li>
                    <li>⬇️ <strong>Offline Download:</strong> Download shows to watch without an internet connection.</li>
                    <li>👶 <strong>Kids Profile:</strong> Safe and fun experiences for children with dedicated profiles.</li>
                    <li>🔒 <strong>Authentication:</strong> Secure login and session management with JWT and NextAuth.</li>
                    <li>🎨 <strong>Modern UI:</strong> Responsive design with dynamic backgrounds, custom fonts, and image assets.</li>
                    <li>📖 <strong>Search & History:</strong> Search for your favorite content and track your viewing history.</li>
                </ul>
